# DemandPulse

Enterprise-scale Retail Revenue Intelligence & Demand Forecasting Platform.

## Overview

DemandPulse is an end-to-end retail analytics and machine learning platform built using the dunnhumby Let's Get Sort-of-Real dataset (~300M synthetic transaction records).

The platform focuses on:
- Revenue and store performance analytics
- Customer segmentation and basket intelligence
- Weekly demand and revenue forecasting
- Revenue target shortfall risk prediction
- Executive decision-support dashboards

## Tech Stack

- Python 3.12, uv
- Polars, DuckDB, Parquet, SQL
- LightGBM, Statsmodels, Greykite, NeuralProphet
- Streamlit, Plotly
- Pytest, Ruff, GitHub Actions

## Development Status

Project initialized. Implementation will follow phased development with feature branches, pull requests, automated testing, and code review.

dunnhumby Let's Get Sort-of-Real: https://www.dunnhumby.com/source-files/
